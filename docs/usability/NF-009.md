# NF-009: Five-user usability evaluation

## Purpose and pass criteria

Evaluate whether users can complete core desktop workflows without
facilitator assistance. Run the same ten tasks with five participants (50
task attempts total). Count a task as independently completed only when the
participant reaches the stated outcome without a facilitator hint or the
facilitator taking control. Participants may use the application's labels and
built-in workflow help; record built-in help use separately.

Pass NF-009 when at least 45 of 50 task attempts are independently completed
(90%). Report the actual numerator, denominator, percentage, and any blocked
tasks. This protocol is not a result; do not mark the threshold as met until
five sessions have been completed.

For the separate three-minute receptionist registration acceptance check,
follow [NF-005](NF-005.md) as well.

## Preparation

- Use an isolated staging environment and synthetic users, appointments, and
  patient data only. Do not expose production or real patient records.
- Prepare accounts for Receptionist, Doctor, Administrator, and Patient
  workflows for each participant, plus the test records needed by the tasks.
- Verify that the desktop client and API are available before each session.
- Assign anonymous participant IDs `P1` through `P5`. Do not record names,
  credentials, or other identifying information.
- Read each task prompt exactly as written. Do not explain navigation or
  point out controls. If a participant asks for help, record the request and
  do not provide a hint before recording the attempt as assisted.
- Ask for permission before collecting any notes or recordings. Avoid screen
  recordings unless separately approved.

## Task prompts and outcomes

Use the appropriate pre-created role account for each prompt. The moderator
should provide only the prompt and any synthetic test data called for.

| # | Role | Prompt | Successful outcome |
|---|------|--------|--------------------|
| 1 | Receptionist | Register the supplied new patient. | A patient ID is shown after successful registration. Record elapsed time; the NF-005 timing check passes at 180 seconds or less. |
| 2 | Receptionist | Find the supplied patient using their ID. | The matching patient appears in the results. |
| 3 | Receptionist | Change the supplied patient's address to the provided synthetic address. | The update succeeds and the selected patient remains visible. |
| 4 | Receptionist | Book the supplied patient with the supplied doctor on the test date. | The participant selects an available slot and sees booking confirmation. |
| 5 | Doctor | Find the supplied patient and open their history. | The requested patient history is displayed. |
| 6 | Doctor | Record the supplied symptoms and diagnosis for the confirmed appointment. | The consultation saves and a visit ID is shown. |
| 7 | Doctor | Add the supplied prescription to that visit. | The prescription saves successfully. |
| 8 | Administrator | Create a Receptionist account using the supplied test credentials. | Account creation confirmation is displayed. |
| 9 | Patient | Create a profile using the supplied synthetic details. | A linked patient ID is shown. |
| 10 | Patient | Book an appointment for that profile with the supplied doctor on the test date. | The participant selects an available slot and sees booking confirmation. |

Use distinct synthetic patient records and free appointment slots so one
participant's actions do not invalidate another participant's tasks.

## Recording sheet

Record one row for every task attempt. Use `Yes` or `No` for independent
completion and built-in help use. Record elapsed time in seconds; use `N/A`
when a task was not completed. Copy the template row once per participant and
task before starting the sessions.

| Participant | Task | Independent (Y/N) | Built-in help used (Y/N) | Time (seconds) | Outcome / observed issue |
|-------------|------|-------------------|--------------------------|----------------|--------------------------|
| P1-P5 | 1-10 | | | | |

Calculate:

`independent completion rate = independent task attempts / 50 * 100`

Separately report the number of Task 1 registrations completed within 180
seconds. Do not infer completion results from code tests or simulated users.

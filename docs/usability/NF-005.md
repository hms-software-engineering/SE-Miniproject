# NF-005: Patient registration within three minutes

## Manual acceptance check

1. Run the desktop client against a staging database and sign in with a
   Receptionist account. Use synthetic patient data only.
2. Open **Patient Management** and select **New patient**. This starts or
   restarts the registration timer and places the cursor in the name field.
3. Enter a name, date of birth (`DD-MM-YYYY`), gender, 10-digit phone number,
   and address. Submit with **Register patient** or `Ctrl+Enter`.
4. Stop at the successful registration message. It displays the elapsed
   `MM:SS` time and whether the three-minute target was met.
5. Pass the timing check when the successful registration response arrives
   within 180 seconds. Invalid dates and phone numbers must be rejected before
   submission, with focus returned to the field that needs correction.

Record the elapsed time and outcome for each run. Do not count validation
failures as completed registrations or use real patient information.
